During the Fall of 2026, I had the pleasure of working with head coach Bryan Torresani 
and the rest of the coaching staff for the baseball team at DeSales University. Coach Torresani
and his staff are innovating how their team operates at the NCAA Division III level. They
have implemented multiple new data collecting technologies to better help with their player development.
One of the new technologies implemented this fall are Blast Motion sensors for all of their hitters. I
created this Python script for Coach Torresani to use to better understand the data he was collecting
from Blast Motion. 

When the script runs, the user has the option to generate a full team report or
individual hitting reports using CSV data downloaded from Blast Motion's website. To run this code yourself,
download the zip file and open the blast_reports.py file. There are sample CSV files as well as sample
reports already within the zip file, so running blast_reports.py isn't necessary to see what the final product
looks like.
